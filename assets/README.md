# Assets Directory

This directory contains images and icons for the Navadrishti portfolio website.

## Structure

```
assets/
├── images/          # Screenshots, mockups, and photos
│   └── .gitkeep
└── icons/           # Custom icons and logos
    └── .gitkeep
```

## Image Guidelines

### Screenshots/Mockups

- Format: PNG or WebP
- Recommended size: 1200x800px
- Optimize for web (<200KB per image)

### Icons

- Format: SVG preferred, PNG fallback
- Size: 48x48px minimum
- Use consistent color scheme

### Logo

- Primary logo: SVG format
- Favicon: 32x32px PNG

## Optimization Tips

1. Use WebP format for better compression
2. Compress images before adding
3. Use lazy loading for images below the fold
4. Provide alt text for accessibility

## Naming Convention

Use descriptive, lowercase names with hyphens:

- `platform-dashboard.png`
- `ngo-interface.png`
- `impact-graph.png`
- `logo-white.svg`
